# Visual Reference Library

This folder contains **reference material for visual direction only**. It is not a source of curriculum, game rules or implementation authority.

## Purpose

The library supports the Visual Production Pipeline for **Aventuras da Maittê**. References are separated by the specific attribute they are allowed to influence so that a design agent does not average unrelated works together or imitate a protected style.

## Reference roles

1. `01-current-game-functional/` — current screenshots: functional reference, **not visual target**.
2. `02-maitte-identity/` — Maittê identity/reference photos or approved character references.
3. `03-mario-map-route/` — spatial readability, route hierarchy, landmarks and destination anticipation only.
4. `04-witch-hat-atmosphere/` — magical storybook atmosphere, scenic richness and fantasy composition only.
5. `05-demon-slayer-expression/` — character expressiveness, pose and motion energy only.
6. `06-bobbie-goods-coloring-warmth/` — cozy coloring-book warmth, rounded forms, enclosed colorable regions and observational detail only.

## Binding synthesis rule

Do **not** copy or reproduce the exact style, characters, UI, compositions or recognizable assets of any reference work.

Use references by role:

- Mario → spatial adventure / route readability.
- Witch Hat Atelier → magical scenic richness / storybook atmosphere.
- Demon Slayer → character acting / expression / motion energy.
- Bobbie Goods → cozy coloring-book warmth / rounded detail language.
- Current game screenshots → functional requirements.
- Maittê references → protagonist identity.

The final visual identity must be **original to Aventuras da Maittê** and subordinate to repository Specs.

## Upload guidance

Prefer a small, curated set over a large dump. Suggested maximum per folder: **2–4 strong images**.

Use clear filenames, for example:

- `map-route-landmark-01.jpg`
- `fantasy-line-depth-02.png`
- `expression-thinking-01.jpg`
- `coloring-detail-density-01.png`
- `maitte-front-reference-01.jpg`

Avoid filenames such as `IMG_1234.jpg` when possible.
