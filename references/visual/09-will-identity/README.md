# Will — Identity Reference

Use this folder for real photographs or approved visual references of **Will**.

## Identity purpose

Will is an **orange mixed-breed cat**. These references exist to preserve his recognizable real-world identity when translated into the stylized visual language of Aventuras da Maittê.

Canonical personality direction for acting/design:

- curious;
- meddlesome / gets into things;
- exploratory;
- playful investigative energy.

## Preserve from the references

Prioritize:

- real orange coat tone/pattern;
- face shape;
- muzzle;
- ear shape and placement;
- eye shape/color when visible;
- body proportions;
- tail shape/carriage;
- recognizable posture/silhouette;
- distinctive markings/features visible in the approved photos.

## Do not

- turn Will into a generic orange cartoon cat;
- copy an existing famous orange-cat character;
- give him Lyra's calm/observant acting personality;
- permanently bind him to a school subject or Skill;
- make him photorealistic if it conflicts with the project character language.

## Acting direction

Useful future production poses may include:

- curious idle;
- peeking into an object/scene;
- investigative look;
- playful discovery;
- success reaction;
- mischievous but friendly movement.

These are acting directions, not permanent gameplay assignments.

## Upload guidance

Prefer 2–4 strong photos, for example:

- `will-front-01.jpg`
- `will-standing-side-01.jpg`
- `will-face-01.jpg`
- `will-exploring-01.jpg`

These images are **identity references**, not public production assets unless separately approved.
