# Aventuras da Maittê: Em Construção

Crie um novo projeto chamado “Aventuras da Maittê”.

Neste momento, faça apenas o bootstrap mínimo do projeto para que possamos estabelecer o repositório e iniciar um processo de desenvolvimento orientado por especificações (Spec Driven Development).

Não implemente ainda o jogo, telas definitivas, mapa, mundos, personagens, puzzles, sistema de progressão, banco de dados ou identidade visual.

Crie apenas uma aplicação funcional mínima, com uma tela temporária contendo o nome “Aventuras da Maittê” e a indicação “Projeto em construção”.

Este projeto será posteriormente governado por especificações versionadas no GitHub. Decisões de produto, UX, narrativa, pedagogia, arquitetura e gameplay não devem ser presumidas nem antecipadas nesta etapa.

O objetivo desta primeira execução é exclusivamente estabelecer a base técnica inicial do projeto.
