# Progression

**Status:** DECIDED foundation; numerical economy PROVISIONAL.

## Two progression axes
1. **Subject choice:** open from the Overworld. No global requirement to finish one discipline before another.
2. **Within-world path:** sequential space-by-space progression where pedagogically/game-design appropriate.

## Primary progression language
Color restoration is the primary visible expression of progress. XP supports the system but should not replace environmental feedback.

A completed Activity Slot may contribute to:
- local board restoration;
- world/Overworld restoration percentage/state;
- Maittê color restoration;
- XP;
- narrative/tool recovery milestones;
- access to the next local space.

## Recovery milestones
Stolen pencils, crayons, markers, paints, watercolors and other tools can serve as narrative milestones, often associated with restored minions/landmarks.

## Future reward space
Avatar/clothing customization, additional avatars, companion choices and richer rewards are FUTURE. MVP architecture should not preclude them but must not implement them merely for completeness.

## No dice
Board movement is earned through challenge completion, one Activity Slot at a time; there is no random dice movement in the core model.
