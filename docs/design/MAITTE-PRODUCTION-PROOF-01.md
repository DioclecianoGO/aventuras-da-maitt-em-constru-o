## 3. Primary production hypothesis

**PROVISIONAL HYPOTHESIS TO TEST:** use one clean full-color character painting as the visual source, derive one colorless/base representation from that same painting, and reveal the original full-color painting through independent restoration masks.

Conceptually:

`same full-color painting`
`-> colorless base`
`+ restoration masks`
`-> progressively reveal color from the exact same painting`

Why this is preferred for the proof:

- all restoration states preserve exactly the same pose and drawing;
- no identity drift is introduced between restoration regions;
- watercolor texture remains spatially aligned;
- no separate regeneration is required for hair, skirt, glasses, etc.;
- runtime restoration can remain derived from existing gameplay facts.

This hypothesis is not yet the final physical contract. If it fails quality, performance or authoring criteria, the proof may recommend multiple authored layers or another presentation-only representation.

## 6. Photoshop preparation procedure

### P1 — Preserve originals

1. Open the selected C1 proof-source image.
2. Save a new PSD immediately.
3. Keep the original source untouched in a hidden reference group.
4. Add the approved Character Master as a separate hidden reference.

### P2 — Create transparent character cutout

Create a non-destructive transparent cutout of the entire character.

Review especially:

- outer hair curls;
- lighter hair streak / bead detail;
- glasses edges;
- fingers/hands;
- skirt pleats;
- sock edges;
- shoelaces / shoes;
- soft watercolor edge texture.

Do not permanently erase source pixels merely to obtain transparency. Prefer a layer mask until the export is approved.

### P3 — Create full-color production source

Create one clean full-color character layer/group from the cutout.

This layer is the visual source from which restoration reveals color.

Do not independently repaint restoration regions.

### P4 — Create colorless base

Derive the stolen-color/base representation from the same aligned full-color painting.

Initial proof direction:

- grayscale/desaturated body/garments/hair;
- preserve line/value/texture detail;
- preserve watercolor texture rather than reducing to flat gray vector shapes;
- keep the green heart saturated through the always-on group.

The proof must verify that the colorless treatment still reads as the same authored illustration rather than a generic grayscale filter artifact.

### P5 — Create independent masks

Create one grayscale mask per binding restoration region.

Mask convention:

- white = reveal the full-color source for the region;
- black = keep the colorless base;
- gray/antialiased values = controlled edge transition only.

Each mask must:

- remain aligned to the exact same painting;
- avoid visible gaps between neighboring regions;
- avoid colored halos outside the intended region;
- preserve watercolor/ink edge softness;
- avoid leaking color into face/skin/background or unrelated garments.

### P6 — Heart always-on validation

With all seven ordinary region masks disabled, the proof must show:

- Maittê predominantly colorless;
- green heart clearly saturated;
- no unintended color leakage from ordinary restoration regions.

### P7 — Independent-region validation

Test every region independently.

Required proof matrix:

- no ordinary regions restored;
- glasses only;
- hairStreak only;
- hair only;
- shirt only;
- skirt only;
- socks only;
- shoes only;
- at least two mixed combinations;
- all regions restored.

The matrix validates independence, not sequence.

## 7. Prompt/generative-edit policy inside Photoshop

Photoshop generative tools may be used for **localized repair only** when a source defect materially affects production quality.

Examples:

- repair a hand/finger defect;
- refine glasses geometry;
- repair a small edge/artifact;
- repair a localized clothing/anatomy defect.

When used:

- make a bounded selection;
- use the approved Character Master as reference when useful;
- explicitly require preservation of unaffected regions;
- compare before/after against the Character Master;
- do not permit a localized repair to become a full identity regeneration.

Masks, transparency boundaries and restoration regions should be authored/reviewed as explicit production masks rather than generated blindly from text.

## 9. Runtime composition hypothesis

The runtime proof should attempt to keep:

`character.maitte.listen-think`

as the stable logical key.

Preferred composition concept:

1. draw the colorless base;

## 13. Acceptance criteria

Production Proof 01 passes when:

1. the selected Maittê `listen-think` painting can be isolated cleanly from the paper background;
2. the same painting supports a convincing colorless base without losing identity/texture;
3. the green heart remains saturated in the fully stolen-color state;
4. all seven restoration regions are independently revealable;
5. independent masks do not introduce visible halos, gaps or misregistration at target scale;
6. mixed restoration combinations remain visually coherent;
7. existing gameplay facts can drive the restoration composition without new persisted visual state;
8. `character.maitte.listen-think` and `MaitteActor` can remain the logical presentation seam;
9. runtime performance is acceptable for tablet-first web use;
10. protected gameplay/domain/evaluation/persistence/content layers require no semantic changes;
11. the result materially preserves the approved Maittê Character Master visual language;
12. the proof produces a clear recommendation for the physical production contract.

## 14. Failure / fallback branches

If one-full-color-plus-masks fails:

### Fallback A — authored color region layers

Use separately prepared aligned raster layers for the restoration regions while preserving one shared base drawing.

### Fallback B — grouped restoration layers

Reduce physical mask/layer count only if multiple semantic regions can remain independently controlled through a packing/atlas technique without changing restoration semantics.

### Fallback C — alternate presentation descriptor

Propose a layer-aware presentation descriptor behind the same logical character key.

Do not respond to proof failure by redrawing Maittê as final JSX/SVG art.
