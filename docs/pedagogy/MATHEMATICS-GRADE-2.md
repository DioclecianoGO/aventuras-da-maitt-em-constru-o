## Initial skill taxonomy
### Number sense / decimal system
- `MAT-NUM-PLACE-01`: units, tens, hundreds/place value.
- `MAT-NUM-COMP-01`: compose numbers.
- `MAT-NUM-DECOMP-01`: decompose numbers.
- `MAT-NUM-REP-01`: connect numeral, written number, base-ten/material and decomposition representations.
- `MAT-NUM-SEQ-01`: numerical sequences/missing values.
- `MAT-NUM-COMPARE-01`: compare/order numbers.
- `MAT-NUM-NEIGHBOR-01`: predecessor/successor.

### Addition
- `MAT-ADD-MEANING-01`: understand additive situations.
- `MAT-ADD-CALC-01`: calculate addition.
- `MAT-ADD-PLACE-01`: algorithm/place alignment and regrouping.
- `MAT-ADD-PROBLEM-01`: solve/create additive problems from meaning, not keywords alone.

### Subtraction
- `MAT-SUB-MEANING-01`: removal/comparison/difference situations.
- `MAT-SUB-CALC-01`: calculate subtraction.
- `MAT-SUB-PLACE-01`: algorithm/place alignment and exchanges/regrouping.
- `MAT-SUB-PROBLEM-01`: solve/create subtractive problems from meaning.

### Plane geometry
- `MAT-GEO2D-RECOG-01`: recognize common plane figures independent of orientation/size/color.
- `MAT-GEO2D-PROP-01`: sides and vertices/defining properties.
- `MAT-GEO2D-COMP-01`: compose figures.
- `MAT-GEO2D-DECOMP-01`: decompose composite figures.
- `MAT-GEO2D-MOSAIC-01`: patterns/mosaics/composition.

### Spatial geometry — supporting workbook content
- `MAT-GEO3D-RECOG-01`: recognize studied solids.
- `MAT-GEO3D-REAL-01`: relate mathematical solids to everyday objects.
- `MAT-GEO3D-SURFACE-01`: plane/curved surfaces.
- `MAT-GEO3D-PARTS-01`: faces/edges/vertices where applicable.
- `MAT-GEO3D-CLASS-01`: classify by properties.

## Exercise families evidenced in the material
Base-ten/material representations; composition/decomposition; sequences and missing numbers; algorithms and contextual problems; recognition/classification of plane figures; figure composition/mosaics; solids; plane/curved surfaces; faces/edges/vertices; matching solids to objects.

These are evidence/families, not UI specs.

## MVP delivery order
### Slice A — numbers/place value
Prove the complete Discover → Practice → Challenge loop using `PLACE`, `COMP`, `DECOMP`, `REP`, `SEQ`, `COMPARE`, `NEIGHBOR` with reusable number-building and number-path interactions.

### Slice B — current study utility
The MVP plan must then include a minimal but useful path for the teacher's current priorities: addition/subtraction algorithms including regrouping/exchanges and problem solving, plus a plane-geometry path. A technically elegant prototype that stops at place value is insufficient as the useful study MVP.

## Difficulty
Difficulty is multidimensional: mathematical complexity + representational distance + task complexity + assistance. Larger numbers alone do not define a new level.

## Mastery evidence
Track independent correct, incorrect and assisted attempts, representation and recent evidence. One correct answer does not establish mastery. Exact thresholds remain to be explicitly decided/configured.
