# Learning Model

**Status:** DECIDED foundation.

## Separation of concerns
Curriculum determines **what** is learned. Content Packs provide study material/items. Puzzle Templates determine **how** the learner interacts. Support Level determines **how much help** is provided. Activity Slots determine **where** an activity appears in the adventure.

Canonical hierarchy:
`Subject → Curriculum → Skill → Learning Objective → Content Pack → Activity`

Activity references `Puzzle Template`, `Difficulty`, `Support Level`, `Guide Pet` and `Activity Slot`.

## Learning cycle
### Discover
Introduce/reactivate a concept with concrete/visual support and worked or partially worked examples. Full assistance does not prove mastery.

### Practice
Controlled variation with formative feedback and optional hints. Repeated errors should alter representation/support rather than simply repeat an identical question.

### Challenge
Collect evidence of independent performance with no answer-revealing support before the first attempt and with representation variation.

## Error model
Wrong answers are diagnostic signals, not punitive failure. Distinguish conceptual, procedural, representation and attention-like errors when evidence allows; do not diagnose a learner from isolated responses.

## Mastery
One correct answer is insufficient. Track independent correct, incorrect and assisted attempts, representation used and recent evidence. Thresholds remain explicit configuration/decision, never UI invention.

## Literacy-aware UX
Because the initial learner is still consolidating literacy, instructions must not depend exclusively on independent reading. Where appropriate use spoken instructions, icons, demonstrations, highlighting and companion narration while still exposing written language for learning.
