# Maittê — Protagonist

**Status:** DECIDED concept; final character sheet PROVISIONAL.

Maittê is represented by the protagonist in the MVP. Future versions may allow other avatars, clothing and customization.

## Visual identity
The character is inspired by the supplied real-world references but must not be realistic. Direction: 2D line-art/storybook, coloring-book warmth, with a light manga/anime influence. Preserve childlike proportions and expressive animation; avoid photorealism.

Approved traits:
- approximately eight-year-old child presentation;
- hair slightly below the shoulders;
- subtle bleached lock, later recolorable/removable;
- skirts are a recurring clothing preference;
- canvas high-top/All-Star-like sneakers without relying on protected branding;
- colorful socks;
- green heart on shirt representing hope.

## Color arc
The villain steals most of Maittê's colors. The green heart remains as the symbol of hope. As XP/progress is earned, color can progressively return to her as well as the environments.

## Animation ambition
Maittê should feel alive: idle movement, expressive reactions and movement between board spaces are desirable. Rich animation is not an MVP blocker; implementation must degrade gracefully to simpler transitions while preserving the game loop.
